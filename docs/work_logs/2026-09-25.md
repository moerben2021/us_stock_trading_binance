## 生产部署步骤

### 1. 配置 Binance API

```bash
# 创建密钥文件
mkdir -p secrets
cat > secrets/account1.key << EOF
API_KEY=your_binance_api_key
API_SECRET=your_binance_api_secret
EOF
chmod 600 secrets/account1.key
```

### 2. 设置账户配置

```bash
# 复制模板
cp configs/accounts/example.yaml configs/accounts/account1.yaml

# 编辑配置
# - 设置账户名称
# - 配置策略参数（DCA 金额、回撤阈值等）
# - 设置执行时间（cron 表达式）
```

### 3. 配置系统参数

```bash

# 编辑配置
# - 设置企业微信 webhook URL
# - 调整日志级别
# - 设置数据库路径
```

### 4. 安装依赖

```bash
pip install -r requirements.txt
```

### 5. 运行测试

