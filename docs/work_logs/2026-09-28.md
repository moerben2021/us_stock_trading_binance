### 2. 关键 Bug 修复
**问题 1：订单成交状态误判**
- **现象**：订单状态 `FILLED`，却提示"未成交"
- **原因**：字段名不匹配（`executedQty` vs `filledQty`）
- **修复**：
  - 修正字段名：`executedQty/cummulativeQuoteQty` → `filledQty/filledTotal`
  - 改进判断逻辑：同时检查 `status` 和 `executedQty`
- **影响**：已成交订单能正确继续后续流程（记录交易、发送通知、更新持仓）

**问题 2：手续费计算不准确**
- **现象**：手续费使用硬编码 0.1% 估算
- **发现**：Binance 美股 API 返回实际手续费字段 `fee`
- **修复**：
  - 从订单详情中提取真实手续费
  - 降级策略：优先使用 API 返回值，无值时才估算
- **数据**：实际费率约 2.9%，是假设值的 29 倍
- **影响**：交易记录、持仓成本、通知内容的手续费准确
