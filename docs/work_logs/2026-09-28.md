### 4. Bug 修复

#### 4.1 数据库变量名不一致
**错误信息**：
```

```

#### 4.2 通知数据库字段缺失
**错误信息**：
```
KeyError: 'recipient'
send_trade_notification 失败 (尝试 1/3): 'recipient'
```

**问题分析**：
- `save_notification` 方法需要的字段：
  - `notification_type`, `recipient`, `content_summary`, `status`, `sent_at`, `error_message`
- `WeComNotifier` 传入的字段不匹配：
  - 使用了 `account_name` 而不是 `recipient`
  - 使用了 `content` 而不是 `content_summary`

**修复**：
修复三处通知记录代码：

1. **交易通知** (`send_trade_notification`)：
```python
self.database.save_notification({
    "notification_type": notification_type,
    "recipient": trade_info.get("account_name", "未知账户"),
    "content_summary": f"{action_cn} {trade_info['symbol']} {trade_info['quantity']}股",
    "status": "success",
    "sent_at": datetime.now(timezone.utc).isoformat(),
    "error_message": None
})
```

2. **告警通知** (`send_alert_notification`)：
```python
self.database.save_notification({
    "notification_type": "alert",
    "recipient": alert_info.get("account_name", "system"),
    "content_summary": alert_info.get("message", "系统告警"),
    "status": "success",
    "sent_at": datetime.now(timezone.utc).isoformat(),
    "error_message": None
})
```

3. **汇总通知** (`send_summary_notification`)：
```python
self.database.save_notification({
    "notification_type": "summary",
    "recipient": summary_info.get("account_name", "system"),
    "content_summary": f"{summary_info.get('summary_type', '汇总')}报告",
    "status": "success",
    "sent_at": datetime.now(timezone.utc).isoformat(),
    "error_message": None
})
```

**提交**：`5ec5f78` - `fix: 修复通知记录到数据库时的字段缺失问题`

### 配置文件位置标准
根据今天的分析和验证，确立了配置文件位置的最佳实践：

**必须在根目录**：
- `pyproject.toml` - Python 项目标准（PEP 518, 621）
- `requirements.txt` - pip 默认查找位置
- `system.yaml` - 代码从根目录加载

- `main.py` - 程序入口

**不必须在根目录**：
- `pytest.ini` - 可用 `pyproject.toml` 替代 ✅ 已删除

### 数据库字段映射关系

**notifications 表结构**：
```sql
CREATE TABLE notifications (
    id INTEGER PRIMARY KEY,
    notification_type TEXT NOT NULL,     -- 通知类型
    recipient TEXT NOT NULL,              -- 接收者
    content_summary TEXT,                 -- 内容摘要
    status TEXT NOT NULL,                 -- 状态
    sent_at TEXT NOT NULL,                -- 发送时间
    error_message TEXT                    -- 错误信息
)
```

**字段映射**：
- `account_name` → `recipient`
- `content` → `content_summary`
- 添加 `error_message` 字段（默认 None）
